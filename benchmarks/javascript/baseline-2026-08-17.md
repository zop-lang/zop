# JavaScript core baseline: 2026-08-17

This baseline used an Apple M3 Max, macOS 26.5, Bun 1.3.6, Rust 1.95,
release-mode Zop, and Topcoat commit
`a2bd596af2a149f38fcf49570481f356a6cb1069`.

Each process measured nine interleaved samples of 20 million `f64` affine
evaluations after warmup. The table records each process median and the median
across three fresh processes.

<!-- markdownlint-disable MD013 -->

| Implementation | Run 1 | Run 2 | Run 3 | Median |
| --- | ---: | ---: | ---: | ---: |
| Zop | 14.225 ms | 14.167 ms | 14.060 ms | 14.167 ms |
| Direct JavaScript | 14.121 ms | 14.150 ms | 14.018 ms | 14.121 ms |
| Topcoat | 14.175 ms | 14.145 ms | 13.997 ms | 14.145 ms |

<!-- markdownlint-enable MD013 -->

Zop was 1.003 times the direct-JavaScript floor and 1.002 times Topcoat.
This is parity, not a measured win. JavaScriptCore eliminated Topcoat's
temporary numeric wrapper cost after warmup. Future optimization work should
target costs that escape the JavaScript optimizer: runtime compilation,
reactive bookkeeping, DOM discovery, host boundaries, and retained allocation.

The same workload then ran in headless Chrome 151.0.7922.138. Each row again
contains the median of nine interleaved samples from three fresh browser
processes.

<!-- markdownlint-disable MD013 -->

| Implementation | Run 1 | Run 2 | Run 3 | Median |
| --- | ---: | ---: | ---: | ---: |
| Zop | 14.900 ms | 14.900 ms | 15.000 ms | 14.900 ms |
| Direct JavaScript | 14.900 ms | 14.700 ms | 15.100 ms | 14.900 ms |
| Topcoat | 15.200 ms | 15.100 ms | 15.400 ms | 15.200 ms |

<!-- markdownlint-enable MD013 -->

Zop matched direct JavaScript and measured 2.0 percent faster than Topcoat
in this Chrome sample. No failure threshold was declared before this first
browser baseline, so the gap is a hypothesis rather than a performance claim.
Future comparisons use the benchmark README's predeclared 5 percent threshold.
