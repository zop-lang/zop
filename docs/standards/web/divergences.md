# Browser divergences

This page records accepted differences between the locked specification profile
and real browser behavior. An entry is an expectation, not a fallback.

Each divergence must name:

- the Zop requirement identifier;
- browser, version range, and operating system;
- upstream issue and specification clause;
- observed and required behavior;
- affected tests; and
- removal condition.

The machine-readable expectation files live under
[`conformance/web/expectations`](../../../conformance/web/expectations).

No divergences are accepted yet.
