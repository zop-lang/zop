# Source maps

[ECMA-426](https://tc39.es/ecma426/) defines source maps for JavaScript,
WebAssembly, and Cascading Style Sheets (CSS). Zop source maps must be
conforming documents that an independent ECMA-426 decoder accepts without
error.

Mappings must preserve:

- generated byte and line positions;
- original file, span, and symbol identity;
- transformed and inlined expression provenance;
- JavaScript, WebAssembly, and generated WGSL locations; and
- stack traces and profiler samples after minification.

Golden JSON is insufficient. Tests decode each map, query both directions, and
open representative failures in current browser developer tools.

> **Status:** Blocked on the source-map emitter and source-file identity in
> high-level intermediate representation (HIR).
